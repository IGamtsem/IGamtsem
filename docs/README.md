# Волейбол Стат: скаутинг матча (веб-приложение)

Реализация P0 из ТЗ «Volleyball Statistics App», версия 1.0. Устанавливаемое веб-приложение (PWA) для планшета и ноутбука, на телефоне работает просмотр и базовый ввод. Без сборки и зависимостей: HTML, CSS и ES-модули. Данные хранятся в IndexedDB на устройстве, после первого открытия приложение работает без сети.

## Что есть

- **Журнал событий как источник истины.** Счёт, переходы, розыгрыши, владения и все отчёты пересчитываются из журнала. Исправление раннего эпизода пересчитывает всё последующее. Противоречия, например несовпадение подающего с расстановкой, отмечаются «проверить».
- **Подготовка.** Команды и игроки с постоянным ID, заявка на матч со своими номерами, импорт списка CSV. Профиль правил (FIVB 2025–2028 или пользовательский), система 5–1, 6–2 или 4–2, режим быстрый или подробный. Шесть стартовых слотов на каждую партию, либеро, первая подача.
- **Быстрый режим (по умолчанию).** Для живого матча: на своей подаче — одно касание (эйс / в игре / ошибка), на подаче соперника — принимающий и оценка приёма, затем итог розыгрыша одной кнопкой с причиной: наша атака, блок, ошибка соперника; атака, блок, эйс соперника, наша ошибка. Если перед этим выбран игрок, очко или ошибка записываются на него, иначе на команду. Остальные касания пропускаются, отчёты показывают, что из-за этого недоступно. Режим переключается на странице матча и на экране записи.
- **Подробный режим.** Касание игрока → действие → оценка. Ожидаемое следующее действие подставляется само: на нашей подаче выбран подающий, после приёма связующий. Терминальная оценка сама завершает розыгрыш, а кнопки «Очко нам / сопернику» завершают его в одно касание с выбором причины. Уточнения необязательны: тип и направление атаки, in/out-system и адресат передачи, участники группового блока, тип подачи, сложность защиты. Ещё есть отмена и повтор, замены (включая двойную одной записью) с проверкой регламента и комментарием, либеро с автоматическим выходом перед передней линией, тайм-ауты, санкции, переигровка, досрочный конец партии и смена стороны отображения. На ноутбуке — горячие клавиши, их можно перенастроить.
- **Лента.** Розыгрыши и касания с фильтрами: партия, игрок, действие, оценка, расстановка, неполные и требующие проверки, поиск по счёту. Можно править касание и итог розыгрыша, вставить пропущенное касание или связанную запись того же очка, изменить стартовую расстановку. История правок хранится вместе с автором, временем и причиной.
- **Отчёты.**
  - Команда по партиям: SO, SO in play, BP, Kill и Eff, приём, покрытие.
  - Распределение очков со сверкой со счётом и график счёта.
  - Игроки: обзор и вкладки атаки, подачи, приёма, защиты, блока и передач.
  - Связующий: основная таблица, матрица связующий — нападающий, направления, фильтры по входу, системе, линии и фазе.
  - Шесть карточек расстановок с SO и BP, таблицы расстановок, приёма в расстановке и составов.
  - Серии.

  У каждого процента есть числитель и знаменатель. При нулевом знаменателе выводится «—», малые выборки отмечены. Есть сортировка и скрытие колонок, концовки как отдельный фильтр.
- **Экспорт.** CSV по любой таблице (UTF-8, с датой формирования, версией данных, шкалой, фильтрами и полнотой) и полный JSON матча с восстановлением из него. Ещё есть резервная копия всего в один файл.

## Чего пока нет

- Серверной синхронизации, ролей пользователей и одного активного редактора на матч. Сейчас всё локально, переносить данные нужно через JSON.
- Записи касаний соперника по конкретным игрокам. Соперник учитывается командой.
- Импорта внешних форматов (Data Volley и др.), видео, координат, XLSX и PDF. Это этап P1.

## Публикация и установка

GitHub Pages: Settings → Pages → Deploy from a branch → ветка с этим кодом, папка `/docs`. На iPad или iPhone откройте адрес в Safari и выберите «Поделиться» → «На экран Домой». В Chrome на ноутбуке выберите в меню «Установить приложение».

## Код

- `js/model/` — справочники Club v1, движок (`engine.js`), отчёты (`stats.js`), JSON-обмен. Без обращений к странице.
- `js/core.js` — состояние и операции записи (добавить, вставить, исправить, отменить и повторить).
- `js/db.js` — IndexedDB. Каждая запись журнала хранится отдельно по UUID, повторная запись не дублируется.
- `js/ui/` — экраны.
- `sw.js` — офлайн-кэш. При изменении списка файлов поднимите `VERSION`.

Приёмочные сценарии T01–T18 и проверка производительности на 5000 событиях: `node --test tests/acceptance.test.mjs` из корня репозитория.
