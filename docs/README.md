# Волейбол Стат (веб-версия)

Веб-приложение для iPhone: статистика волейбольного матча по ходу игры. Работает в Safari, ставится на экран «Домой» и после первого открытия работает без интернета. Данные хранятся на телефоне.

## Публикация

Папка `docs/` публикуется через GitHub Pages: Settings → Pages → Build and deployment → Deploy from a branch → ветка с этим кодом, папка `/docs`. Адрес будет `https://<имя>.github.io/<репозиторий>/`.

## Установка на iPhone

Открыть адрес в Safari → «Поделиться» → «На экран Домой».

## Устройство

Без сборки и зависимостей: обычные HTML, CSS и ES-модули.

- `js/domain.js` — правила счёта и статистика, без обращений к странице
- `js/store.js` — хранение в localStorage, демо-команда
- `js/app.js` — экраны и обработка нажатий
- `sw.js` — офлайн-кэш; при изменении списка файлов поднять `VERSION`

Тесты логики: `node --test tests/domain.test.mjs` из корня репозитория.
