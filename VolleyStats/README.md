# Волейбол Стат

Приложение для iPhone, в котором по ходу матча записываются действия каждого игрока: подача, приём, атака, блок, защита и пас. Счёт считается сам из записанных действий, статистика собирается по игрокам и по сетам, итог выгружается в CSV.

SwiftUI + SwiftData, iOS 17+, без внешних зависимостей.

## Запуск

1. Нужен Mac с Xcode 16 или новее.
2. Открыть `VolleyStats/VolleyStats.xcodeproj`.
3. Выбрать симулятор iPhone и нажать ⌘R.

Для установки на свой телефон: в настройках таргета `VolleyStats` → Signing & Capabilities выбрать свою команду (подойдёт бесплатный Apple ID), подключить iPhone и запустить на нём. Если bundle id `com.igamtsem.VolleyStats` занят, поменяйте его на любой свой.

## Как пользоваться

На вкладке «Команды» создайте команду и добавьте игроков с номерами и амплуа. Чтобы просто посмотреть, как всё работает, есть кнопка «Демо-команда».

На вкладке «Матчи» нажмите «+», выберите команду, введите соперника и формат (3 или 5 сетов, очки в сете). Откроется экран записи.

Запись идёт в два касания: номер игрока, затем кнопка с результатом в строке нужного элемента. Цвет кнопки показывает, что будет со счётом: зелёная даёт очко нам, красная сопернику, синяя оставляет мяч в игре. Розыгрыши, которые закончились без участия наших игроков, записываются кнопками «Ошибка соперника», «Очко соперника» и «Наша ошибка».

Когда сет доходит до 25 (в решающем до 15) с разницей в два очка, приложение предложит его закрыть. Сет можно закрыть и вручную через меню «…». Кнопка ↶ отменяет последнее действие, в том числе возвращает только что закрытый сет. Любое действие из журнала матча можно удалить свайпом, счёт пересчитается.

## Что считается

| Элемент | Результаты | Показатели |
|---|---|---|
| Подача | эйс, сложная, в игре, ошибка | эйсы, ошибки, эйс%, ош% |
| Приём | идеально (#), хорошо (+), плохо (−), ошибка | позитив% (# и +), отлично% |
| Атака | очко, в игре, заблокирована, ошибка | результативность (очки/атаки), эффективность (очки − ошибки − блоки) / атаки |
| Блок | очко, касание, ошибка | очки блоком, касания |
| Защита | поднял, ошибка | |
| Пас | точный, неточный, ошибка | |

Итог по игроку: очки (эйсы + атаки + блоки), ошибки (все ошибки плюс заблокированные атаки) и разница +/−.

## Устройство кода

```
VolleyStats/
  Domain/   типы действий, правила счёта, подсчёт статистики (только Foundation)
  Models/   модели SwiftData, запись и отмена действий, экспорт CSV
  Views/    экраны: команды, матчи, запись матча, статистика
```

Счёт нигде не хранится отдельно, он всегда выводится из списка действий, поэтому отмена и удаление не могут его рассинхронизировать. Действие хранит UUID, номер и имя игрока на момент записи: если игрока удалить из состава, его статистика в старых матчах сохранится.
